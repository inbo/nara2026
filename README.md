# nara2026

Scripts voor de analyses van het Natuurrapport 2026.

-\> zie folder `src`

De .Rmd-bestanden die beginnen met een cijfer (01, 02, ...) zijn scripts die gebruikt worden om maatregelen uit de scenario's op kaart te zetten

De .Rmd-bestanden die beginnen met een 'x' (x1\_, x2\_, ...) zijn ondersteunende scripts die gebruikt worden voor deelanalyses of om generieke kaarten aan te maken, zoals de vernattingscontouren of de polygonen van natuur om de infiltratiegebieden te berekenen (x3_natuur_voor_analyse).
